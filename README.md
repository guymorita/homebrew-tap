# guymorita/tap

Homebrew casks for my Mac apps.

```bash
brew install --cask guymorita/tap/moxspeak
```

## MoxSpeak

Select text anywhere on your Mac, press Control+Option+S, and hear it read aloud.
Apple silicon, macOS 14 or later.
